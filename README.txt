Japanese Reader — unified desktop workspace

Use Start Reader.cmd, or your existing Start Live Reader.cmd shortcut.
Existing Fortune Weave libraries are reused at http://127.0.0.1:18744.
New portable libraries use http://127.0.0.1:18745.

Paste text or Type / edit text opens a temporary reading passage.
Save this text keeps it in your local library.
Choose Read from > OBS projector or Game window, then Use this source,
for optional visible-window OCR. Keep the selected dialogue unobstructed.
Enable Automatically save new captured text if you want a persistent capture journal.

Select Japanese words for dictionary lookup.
A / D switches dictionaries with results. Left / Right navigates search history.
These shortcuts are inactive in text fields.

Translation is optional: LM Studio or a separately installed Argos pack.
No dictionaries, models or personal passages are included in the GitHub source.
Read UNIFIED-DESKTOP.md for details and README.md for portable setup.
The native iOS app is unchanged by this desktop merge.
