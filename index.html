   How recognition works · 使用說明
   
Choose Pasted text, OBS projector, or a visible game window in Read from. Keep captured dialogue uncovered. Manual recognition is the default: click a recognition button when ready. Automatic recognition is optional. English and Traditional Chinese translations run locally in LM Studio using your selected model. Dictionary lookup works without translation. Start with HDR off for capture.

  Recorder settings & what it sees
  
Saved automatically in your current reading library. Capture reads the selected OBS projector or game window. Recognized Japanese stays temporary unless automatic saving is enabled; review it for recognition mistakes. No extracted script is available for this game.

  

  

   
   
   
  

  
If menus or background text are being saved, narrow the capture area. Minimized or rapidly skipped dialogue may be missed; some game display modes may require the game to be active. The journal saves stable screen observations, not a guaranteed complete game transcript.
