   How recognition works · 使用說明
   
Choose Pasted text, OBS projector, or a visible game window in Read from. Keep captured dialogue uncovered. Manual recognition is the default: press R (or the recognize button) when ready, Ctrl+R for the whole game screen, and Q to cancel. Automatic recognition is optional. Dictionary lookup works without translation. Start with HDR off for capture.

  擷取範圍 · Capture area
  
Saved automatically in your current reading library. Capture reads the selected OBS projector or game window. Recognized Japanese stays temporary unless automatic saving is enabled; review it for recognition mistakes.

  

  

   
   
   
  

  
If menus or background text are being saved, narrow the capture area. Minimized or rapidly skipped dialogue may be missed; some game display modes may require the game to be active. The journal saves stable screen observations, not a guaranteed complete game transcript.
